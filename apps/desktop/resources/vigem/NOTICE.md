# ViGEmBus

This folder holds the official **ViGEmBus** setup redistributable from Nefarius
([github.com/nefarius/ViGEmBus](https://github.com/nefarius/ViGEmBus)).

- License: MIT
- Download: `pnpm --filter @virtual-shock/desktop download-vigem`

Virtual Shock bundles this installer and may run it once (elevated) so the user
does not need to fetch the driver separately.
